# SolidAção - Projeto Universitário

## Sobre o Projeto

Este projeto foi desenvolvido como parte de um trabalho universitário, com foco em desenvolvimento social utilizando tecnologia. O objetivo é criar uma aplicação WEB que facilite o processo de doações, permita que pessoas em situação de vulnerabilidade possam se cadastrar para receber apoio e ajude a divulgar a ferramenta para encontrar mais doadores para a organização.

A plataforma conecta doadores e beneficiários, promovendo solidariedade, ampliando o alcance das ações sociais e ajudando cada vez mais famílias.

## Funcionalidades

- Cadastro de pessoas que precisam de ajuda (com armazenamento em banco de dados)
- Área para doadores contribuírem com alimentos, dinheiro ou tempo
- Informações sobre pontos de coleta e contato
- Divulgação da ferramenta para atrair novos doadores

## Tecnologias Utilizadas

- HTML
- CSS
- JavaScript
- Banco de Dados

## Objetivo Social

Ajudar famílias e indivíduos em situação de vulnerabilidade, promovendo justiça social e solidariedade por meio da tecnologia, além de ampliar a rede de doadores para potencializar o impacto social.

## Como usar

Basta abrir o arquivo `index.html` em seu navegador para acessar a plataforma.
